# 🕌 Trace Quran - Interactive Quranic Learning App

A modern React application for learning Quranic Arabic through interactive tracing, audio playback, and repetition.

## ✨ Features

- 📖 Complete Quran with all 114 Surahs
- 🔊 High-quality audio recitations
- ✍️ Interactive letter tracing
- 👂 Listen & Trace mode
- 🔁 Customizable repetition
- 🔖 Bookmarking system
- 💾 Progress tracking
- 📱 Responsive design
- 🎨 Beautiful Islamic theme
- 📢 AdMob integration

## 🚀 Getting Started

```bash
git clone https://github.com/asim888/Traceable-Quran-App.git
cd Traceable-Quran-App
npm install
npm start
